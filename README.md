## 🤖 Categories

The library is organized into four main categories:

### [Trading Agents](./trading-agents/)
AI agents focused on trading, financial analysis, market monitoring, and investment strategies.

- Trading Agent - Portfolio management and execution
- CopyBot Agent - Copy trading from successful wallets
- Risk Agent - Portfolio risk management
- Strategy Agent - Trading signal evaluation
- Whale Agent - Whale activity detection
- Funding Agent - Funding rate analysis
- Liquidation Agent - Liquidation event monitoring
- Funding Arbitrage Agent - Cross-exchange arbitrage
- CoinGecko Agent - Market data analysis
- Listing Arbitrage Agent - New listing detection
- New/Top Agent - New coin and top gainer analysis

### [Content Agents](./content-agents/)
AI agents focused on content creation, media processing, analysis, and distribution.

- ShortVid Agent - Video subtitle and voiceover generation
- Clips Agent - Video clip extraction and processing
- Sentiment Agent - Social media sentiment analysis
- Chat Agent - Interactive chat bot
- Focus Agent - Productivity monitoring
- Compliance Agent - Content compliance checking
- Tweet Agent - Twitter/X content generation
- TikTok Agent - TikTok content interaction
- Research Agent - Content research idea generation

### [Blockchain Agents](./blockchain-agents/)
AI agents focused on blockchain analysis, crypto monitoring, and on-chain data processing.

- Sniper Agent - New token launch detection
- TX Agent - Transaction monitoring
- Solana Agent - Solana blockchain analysis
- Chart Analysis Agent - Technical chart analysis
- RBI Agent - Research-based investment analysis

### [Utility Agents](./utility-agents/)
General-purpose utility agents that provide foundational functionality and automation tools.

- Phone Agent - Voice-activated phone system
- Code Runner Agent - Automated code execution
- Million Agent - Knowledge-based Q&A system
- Base Agent - Core agent functionality

## 📦 Installation

Each agent has its own dependencies and installation instructions. Please refer to the individual agent directories for specific setup guides.

General requirements:
- Python 3.8+
- Various Python packages (see individual agent READMEs)
- API access for certain services

## 🚀 Getting Started

1. Clone this repository:
```bash
git clone https://github.com/USERNAME/Library-of-AI-Agents.git
cd Library-of-AI-Agents
```

2. Navigate to the category of your interest:
```bash
cd trading-agents
# or
cd content-agents
# or
cd blockchain-agents
# or
cd utility-agents
```

3. Explore the agents in each category and follow the specific setup instructions in their README files.

## 🔧 Usage

Each agent has its own usage pattern, but most follow a similar structure:

```python
# Import the agent
from agent_folder import AgentClass

# Initialize the agent
agent = AgentClass()

# Run the agent
agent.run()
```

See each agent's README for specific usage instructions and configuration options.
